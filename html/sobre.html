Proposta

Qual a demanda ou problema?

Necessidade de uma alternativa ao youtube sem ter scroll infinito

Quem possui essa necessidade?

Pesssoas que querem ver videos do youtube sem o risco de perder o foco e tempo no scroll infinito

Qual a solução desenvolvida?

Criar uma playlist de videos no site YourMind para guardar videos preferidos, assistir depois, etc. sem ter scroll infinito

Quam sera o publico alvo?

o site foi feito para publicos diversos, desde jovens ate adultos e idosos.

Quais tecnologias utilizadas?

o site usa iframes do youtube. usa codigo Js para separar o id do link, feito por nilo, para separar o id do link e colocar no iframe, alem de bibliotecas como @media para deixar o site responsivo.
